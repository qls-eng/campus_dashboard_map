## 四、未覆盖与说明

1. **未做自动化单元测试**：图表函数依赖 Streamlit 运行时，本轮验证以 `AppTest` 断言 + 截图核对为主；纯函数 `clean_dataframe` 可加 pytest，未在本次范围内展开。
2. **TC-20 / TC-21 / TC-26 为部分执行或未执行**：图层开关与坐标拾取依赖真实鼠标交互，只确认了控件存在与默认状态。
3. **TC-15 的 60 秒刷新**：只确认开关存在与 `@st.fragment(run_every=60)` 装饰器，未做 60 秒以上的连续观察。
4. **TC-27 / TC-28 / TC-30 的点选为模拟**：通过直接写入 `type_bar_select` 控件的选区状态来触发 `on_select` 回调链路（选区列表 → `_sync_drill_type` → `session_state.drill_type` → 图表取数），逻辑链路已验证；但"真实鼠标点击 Plotly 柱子"这一层尚未在浏览器里人工点过，需线上手动复核一次。
5. **数据为模拟数据**：全部数值来自固定种子生成的 raw CSV，使用率由人流量除以建筑容量反算，可复现、可当场验算，但不代表真实校园人流。
